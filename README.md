📊 Blinkit Sales Dashboard – Power BI

## 📌 Project Overview

This project presents an **interactive Power BI dashboard** developed using Blinkit sales data to analyze business performance, customer behavior, and operational trends. The dashboard enables stakeholders to make **data-driven decisions** by visualizing key metrics in a clear and insightful manner.

---

## 🎯 Objectives

* Analyze overall **sales performance**
* Track **order trends** and revenue growth
* Identify **top-performing products and categories**
* Understand **customer purchase behavior**
* Monitor **city-wise / outlet-wise performance**

---

## 🛠 Tools & Technologies

* **Power BI Desktop**
* **DAX (Data Analysis Expressions)**
* **Power Query**
* **Microsoft Excel / CSV** (Data Source)

---

## 📂 Dataset Details

* Order ID
* Order Date
* Product Category
* Product Name
* Quantity Sold
* Sales Amount
* City / Outlet
* Customer Type


## 📈 Dashboard Features

* **Total Sales, Orders & Average Order Value (KPIs)**
* **Category-wise and Product-wise Sales Analysis**
* **Time-based Trend Analysis (Daily / Monthly)**
* **City / Outlet Performance Comparison**
* **Interactive Filters & Slicers**
* **Dynamic Visuals for Better Insights**

## 🔍 Key Insights

* Identified **top revenue-generating categories and products**
* Observed **peak order periods** and seasonal trends
* Analyzed **regional sales performance**
* Highlighted customer purchasing patterns

## 🚀 How to Use

1. Download the `.pbix` file from this repository
2. Open it using **Power BI Desktop**
3. Refresh data (if dataset is included)
4. Explore the dashboard using filters and slicers
